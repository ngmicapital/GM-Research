# Content Scout — Master Channel List

This is the seed list for the Content Scout. Each channel includes its YouTube
channel ID (where available) and category. The scan script uses these to check
RSS feeds for new uploads.

## How to find a YouTube Channel ID
- Go to the channel page
- View page source or use: https://www.youtube.com/feeds/videos.xml?channel_id=CHANNEL_ID
- Or use the script: `python scan_channels.py --resolve "channel name"`
