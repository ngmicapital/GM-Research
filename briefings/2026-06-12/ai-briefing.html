Released June 9, Fable 5 is Anthropic's first generally available Mythos-class model. Its 80.3% on SWE-bench Pro is the decisive number — prior leader Opus 4.8 stood at 69.2%, and GPT-5.5 at 58.6%. Signal: the 80.3% SWE-Pro figure is the one to hold. Verified is near-solved and no longer discriminates; Pro is the board where model capability actually differs, and an 11-point gap over Opus 4.8 is larger than any single-cycle swing we have tracked this year. If your evaluation suite still runs on Verified, run it again on Pro.

§07 — Research Radar

Three papers on agent memory architecture — the infrastructure layer that increasingly determines whether a multi-step AI workflow succeeds or degrades over time.

Memory for Autonomous LLM Agents — comprehensive survey (arXiv 2603.07670)

Agent memory

"Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers" (March 2026) offers the most thorough account to date of how memory is designed, implemented and evaluated in modern LLM agents. The paper formalises agent memory as a write-manage-read loop and introduces a three-dimensional taxonomy spanning temporal scope (episodic, semantic, procedural), representational substrate (parametric weights, key-value stores, vector DBs, graphs), and control policy (when to store, retrieve, forget). Key finding: current evaluation benchmarks do not test all four core competencies — accurate retrieval, test-time learning, long-range understanding, and selective forgetting — so benchmark scores systematically overstate memory capability.

Why it matters: if you are deploying any multi-session agent — scheduling bots, research pipelines, anything that carries state across more than one conversation — the write-manage-read framing is the right abstraction to use when debugging failures. Most real-world memory problems are manage (what to keep, what to evict) and read (retrieval precision), not write.

H-MEM: Hierarchical Memory for Long-Term Reasoning (EACL 2026)

Memory efficiency

Published at EACL 2026, H-MEM introduces hierarchical memory vectors with positional index encoding, enabling layer-by-layer retrieval without exhaustive similarity search across the full memory store. On long-range reasoning benchmarks, H-MEM cuts retrieval latency significantly while matching or exceeding flat-vector retrieval on accuracy. Relevant for anyone building agents that accumulate large memory stores over many sessions and find that retrieval latency becomes the bottleneck before quality does.

Governing Evolving Memory in LLM Agents — safety risks (arXiv 2603.11768)

SafetyRisk

"Governing Evolving Memory in LLM Agents: Risks, Mechanisms, and the SSGM Framework" argues that as agents update their memory over time, two underappreciated risks compound: memory drift (gradual divergence from ground truth as updates compound errors) and memory injection (adversarial manipulation of stored context). The Stability and Safety Governed Memory (SSGM) framework proposes write-time validation, provenance tagging, and periodic consistency checks as mitigations. The security angle is directly relevant: if a briefing bot or research agent stores information retrieved from untrusted web sources in long-term memory without provenance controls, it can be poisoned through the content it reads.

Practical implication: any agent with write-access to a memory store that also reads from external or user-supplied sources — including these briefings' web fetch steps — should implement provenance tagging on stored facts and run consistency checks when memory age exceeds a configurable threshold. SSGM's mitigations are not complex to implement; the risk of not implementing them grows with agent deployment time.
