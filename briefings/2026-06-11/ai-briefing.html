§02 — Claude Ecosystem

June's Claude Code drop is about control surfaces, not capability: safe-mode, /cd, fallback-model chains, and enterprise MCP-policy fixes — and Fable 5 is now one /model command away.

Claude Code June update — safe-mode, /cd, and fallback-model chains ⚡

Claude CodeHarness

The June release leans operational. New: --safe-mode (and CLAUDE_CODE_SAFE_MODE) starts a session with all customizations disabled for clean troubleshooting; /cd moves a session to a new working directory without breaking the prompt cache mid-session; disableBundledSkills hides bundled skills, workflows and built-in slash commands from the model; and fallbackModel configures up to three fallback models tried in order when the primary is overloaded or unavailable.

What actually changes the day: the two that matter for Tony's workflows are /cd and fallbackModel. Cache-preserving directory switches kill the cold-restart tax when you hop between the briefings repo and a worktree; the fallback chain means a saturated Opus 4.8 degrades gracefully to a named backup instead of stalling a scheduled task. Set a fallback chain on the briefing bots.

Enterprise MCP policy enforcement fixed

MCPEnterprise

A cluster of managed-policy bugs is resolved: allowedMcpServers / deniedMcpServers are now enforced on reconnect, on IDE-typed configs, on --mcp-config servers during the first session after install, and before remote settings finish loading — plus a fix for slow cold starts in orgs without remote settings. Niche, but it closes a real window where denied servers could load before policy applied.

Fable 5 lands in Claude Code via /model fable

New tierAnthropic

The Mythos-class tier above Opus — announced June 9 — is now selectable in Claude Code with /model fable after claude update. Fable 5 prices at roughly 2× Opus (carry from yesterday's launch coverage).

Position: reserve Fable for the genuinely hard reasoning and security work; Opus 4.8 stays the everyday default, including for these briefings. The 2× cost only earns its keep on tasks where the marginal reasoning matters — don't route routine generation through it.

§06 — Workflow & Tools

MCP's first stateless spec is now a release candidate — MCP Apps (server-rendered UI in sandboxed iframes), Tasks for long-running work, and OAuth-aligned auth — final ships July 28.

MCP spec hits release candidate — stateless core, MCP Apps, Tasks ⚡

MCPSpec RC

Out of the MCP Dev Summit (Bengaluru, June 9–10), the next spec is now a public release candidate. The headline deliverables: a stateless protocol core that scales on ordinary HTTP infrastructure; an Extensions framework; Tasks for long-running work; MCP Apps, which let a server ship server-rendered HTML rendered inside a sandboxed iframe in the host; authorization hardening aligned to OAuth / OpenID Connect; and a formal deprecation policy. Final spec ships July 28, 2026.

Why it matters here: MCP Apps formalises "server-as-UI" — the same iframe-rendered-widget mechanism this briefing's own interactive visuals ride on — so expect a wave of MCP servers that return live interfaces, not just JSON. The stateless core is the real infra unlock: it makes serverless, horizontally-scaled MCP practical. Scale check: the SDKs hit 97M monthly downloads in March and the registry is past 9,400 public servers with native support from Anthropic, OpenAI, Google and Microsoft.

AWS MCP Server now generally available

MCPGA

Amazon's official AWS MCP Server is now GA, broadening the managed first-party server field alongside the Looker, Salesforce Data 360 and other enterprise connectors that have landed over the past month. For anyone building agents against AWS, this replaces a pile of bespoke tool wrappers with one vendor-maintained surface.

§07 — Research Radar

Three papers on the agentic-RL and inference-efficiency frontier — where the gains now come from the harness and the serving stack, not just the weights.

Rethinking Agentic RL — RL-PLUS (arXiv 2604.27859)

RL post-training

Proposes RL-PLUS, a hybrid-policy optimization framework that synergises internal exploitation with external data, combining Multiple Importance Sampling with an Exploration-Based Advantage Function so an agent can transcend the limits of its base model. The live question it speaks to: whether RL post-training can keep pushing agent capability past the pretraining ceiling, rather than just sharpening what's already there.

Agentic Code Reasoning (arXiv 2603.01896)

Code agents

Shows that semi-formal structured reasoning lifts agentic code question-answering to 87% accuracy — a marked gain over both single-shot and standard agentic reasoning. This is the structured-reasoning-over-code thread that directly feeds tools like Claude Code; the takeaway is that imposing light formal structure on the reasoning trace, not just more tokens, is where the accuracy comes from.

Workload-Router-Pool for LLM inference (arXiv 2603.21354)

Serving

A vision paper from the vLLM Semantic Router project: route incoming requests to specialised model pools by workload type to cut inference cost without sacrificing quality. The serving-layer counterpart to the speculative-decoding wave — increasingly the unit-economics gains in production come from the router and the pool, not the model.
