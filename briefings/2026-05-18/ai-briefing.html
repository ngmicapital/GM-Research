Research Params: 1.2B (compact) Strategy: coarse-to-fine parsing

Per arXiv cs.AI current listing: MinerU2.5 is a 1.2B-parameter document-parsing vision-language model that achieves state-of-the-art recognition accuracy with substantial computational efficiency via a coarse-to-fine parsing strategy — the model first identifies document structure at low resolution, then re-attends at higher resolution only to identified regions. The compactness is the headline (1.2B is firmly in the "fits on a consumer GPU" tier); the recognition accuracy claim sits against larger models like Qwen2-VL-72B and InternVL2-26B.

⚡ Why it matters in 6 months: Direct relevance to academic-research workflows (Allen monetary-theory paper, transcript-intelligence skill). A 1.2B VLM that parses PDFs at SOTA accuracy is the production-tier substitute for the API-tier OCR-and-extract pipelines currently running on Claude Sonnet / Opus. Local-fallback economics: a $200 consumer GPU running MinerU2.5 can process roughly 10,000 PDF pages / hour at zero marginal cost, vs. ~$50 / 10,000 pages on Claude API. For the citation-survey work specifically — where the input is hundreds of court rulings and academic PDFs — this is the cost-floor model worth tracking through to next quarter.

SANA-Video — small diffusion model, linear attention, high-resolution video

Research Architecture: linear attention + constant-memory KV cache Resolution: high (1080p-class)

Per arXiv: SANA-Video is a small diffusion model that efficiently generates high-resolution, high-quality videos with strong text-video alignment using linear attention and a constant-memory KV cache. The headline claim is competitive performance at lower cost and higher inference speed — the model's compute footprint is roughly an order of magnitude smaller than comparable transformer-based video diffusion (Sora-class) while maintaining text-video alignment scores. Pair-up signal with Gemma 4 MTP from Issue #49 (speculative decoding) and SubQ 1M-Preview (§01) — linear / subquadratic architectures are the architecture-of-the-month for May 2026.

⚡ Why it matters in 6 months: Video generation is the AI capability that has been most cost-bound — Sora-class models cost ~$0.50–1.00 / 5-second clip even at API tier. SANA-Video's linear-attention architecture suggests the cost-curve breaks in the next 6 months, similar to how speculative decoding broke the text-cost curve in late 2025. For dc's stack, this isn't actionable yet (briefings don't generate video), but it changes the calculus for what's economically feasible in marketing / content / education by Q4 2026. The structural through-line: linear-attention is now the production-tier substitute for quadratic transformers across text (SubQ), image (SANA-Image), and now video (SANA-Video).

AutoDev — sandboxed agentic software engineering

Research Environment: Docker sandbox Scope: code + test generation

Per arXiv: AutoDev is an AI-driven software-development framework that automates complex engineering tasks within a secure Docker environment, achieving high performance in code and test generation. The framing is "agentic software engineering" — the agent runs file inspection, command execution, code edits, and test validation in a controlled sandbox without escalation outside the container. This is the same primitive OpenAI Agents SDK shipped on April 15 (sandbox execution) and what Anthropic ships via Claude Code's bash + edit tools, packaged as a research artifact rather than a commercial product.

⚡ Why it matters in 6 months: The research-side validation of what the commercial agent frameworks (Microsoft Agent Framework 1.0, OpenAI Agents SDK, Claude Code) are already shipping in production. The interesting question for dc's stack — is there a useful primitive in AutoDev that isn't in Claude Code? Most likely answer: no, because the sandbox-execution primitive has already commoditised in the past six weeks. The paper's value is benchmark evidence that sandboxed agentic SE works at academic-grade rigour, not as a parts catalogue.

Linear / subquadratic attention — SANA-Video and SubQ proof points

Update Research Architecture-of-the-month for May SubQ: 12M context SANA-Video: linear attention + constant-memory KV cache

The two architecture-class proof-points from §01 (SubQ 1M-Preview) and §07 (SANA-Video) signal the same structural shift: linear-attention / subquadratic architectures are now production-tier substitutes for quadratic-attention transformers across modalities. Text (SubQ 12M context), image (SANA-Image carry from earlier issues), video (SANA-Video) — three modalities, one architectural pattern. The honesty caveat: long-context recall on subquadratic models has historically traded off against shorter-context attention quality; SubQ has not yet published independent NIAH or RULER scores.

⚡ So what: Same structural read as MTP. The unit-economics floor for AI inference is moving down faster than the AI-crypto compute thesis was priced for. For the briefings-site stack specifically, no migration is needed in 2026 — Claude Opus 4.7 + Sonnet 4.5 are both well below the cost-pressure threshold for daily briefing volumes. But the 2027 migration question opens up: if Anthropic ships an MTP-and-linear-attention Sonnet 5.x at 1/3 the cost of Sonnet 4.5, the briefings-stack migration becomes a 1-day pricing decision, not a multi-week capability decision.

🔬 Plain-English Explainer

Two architectural shifts are happening at once, and they compound. Speculative decoding (Gemma 4 MTP) makes a model run 3× faster by letting a small fast model guess ahead and a big slow model verify in parallel — same answer, third of the cost. Linear attention (SubQ, SANA) makes a model scale to much longer inputs (12M tokens, hours-of-video) without the cost exploding quadratically — same architecture class, but the cost-curve no longer breaks at long context. Combined, they mean a 2026-vintage frontier model running on 2027 inference hardware will cost roughly one-tenth what a 2025-vintage frontier model cost on 2025 hardware. The downstream implications are uneven: for traders, this is the structural reason AI-crypto compute names (AKT, TAO, RENDER) had a tougher unit-economics race against centralised inference than the basket-rotation thesis priced for; for academic researchers, this is the reason local-fallback economics (MinerU2.5 on a consumer GPU) become real by mid-2027; for the briefings-site stack, this is the reason the migration calculus opens up in 2027 rather than 2026.
