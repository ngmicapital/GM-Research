TL;DR — Driving Thesis

Amazon has now announced its agreement for Decart's core software and three founders, reportedly worth about $7.5B, making it the day's biggest development; it follows last issue's report of talks.

Two things to act on: first, treat the Amazon-Decart agreement as a signal that large cloud providers are buying inference-efficiency software and teams, so check whether your stack depends on Decart's optimization tooling and whether the pending regulatory review could change it. Second, if you run Claude Code, decide whether to pilot Claude Ship's approval agents in observation mode before enabling automatic merges. Three to monitor: whether Opus 5.6 gets a formal announcement, Venice's buyback cadence after its emissions cut, and whether the Qwen3.8-27B derivative wave produces benchmarked successors.

Model Landscape

This cycle's model news is mid-size coding and reasoning releases built on open-weight bases, not a new frontier flagship.

Cognition's SWE-2.1 doubles down on reinforcement learning

Cognition put out SWE-2.1 on 24 November, the successor to the coding model behind Devin, and its own figures suggest roughly twofold gains over the previous generation. Its post-training is reinforcement-only and sits on top of Moonshot's open 2.8T-parameter Kimi K3 base. The line ships as three variants, so the real test is whether independent evaluations match the vendor numbers.

Sakana's Namazu Small: 30B reasoning on NVIDIA's open base

Sakana announced Namazu Small on 25 November. It is a 30-billion-parameter reasoning model, produced by further training NVIDIA's open Nemotron 3 Nano. Sakana says it out-searches a model four times its size; treat that as a vendor claim until someone replicates it.

Moonshot opens the weights of Kimi K3.1 Pro

Moonshot has released open weights for Kimi K3.1 Pro. It is a natively multimodal mixture-of-experts model with 2.8T total parameters, about 104B active per token, and a 1-million-token context window. Open weights at this scale matter more for self-hosting economics than for raw leaderboard position.

Ideogram moves to 4.6 in the image lane

Ideogram's stable line now reads 4.6, dated 19 November. The 4.5 model had arrived on September 30, 2026. The cadence is quick, so expect further point releases rather than a single headline upgrade.

Claude Ecosystem

Anthropic's week is about developer plumbing: a code-review agent suite, Skills over MCP, and an unreleased Opus model in stealth testing.

Claude Ship puts agents into review and merge approval

Claude Ship is a set of agents that review, repair and approve software changes under rules a development team sets. PR Steward and Claude Approvals are in beta, while Code Review became generally available in October. Automatic approval only becomes possible where repository settings and organisational policy allow it. Anthropic recommends starting in observation mode, and charges are based on token consumption.

Skills over MCP reaches public beta

On 24 November Anthropic opened Skills over MCP in public beta for Claude and Claude Code. Server-side changes flow to every connected client without a separate install. It is on by default for Pro, Max and Ultra plans, and Team plans need an admin to switch it on. Claude Code needs version 2.1.331 or later to use the beta.

⚡ Update: Unannounced Opus 5.6 appears in Claude Code

Reports say Anthropic is quietly routing an unannounced model, Opus 5.6, to select Claude Code users. Early testers describe stronger coding and 3D rendering ahead of a possible launch. As of 25 November, no model ID or pricing had been disclosed. Treat this as unconfirmed until Anthropic publishes a model card.

Claude Code 2.1.332 and a brief API incident

The 2.1.332 build pairs MCP skill support with computer-use changes and a batch of reliability and memory fixes (a broad update across the terminal, VS Code and Desktop). Separately, elevated errors affected five Claude models for roughly 24 minutes on the night of 24 November, and the incident is now resolved.

Decentralized AI

The clearest shipped mechanism in decentralized AI this week is Venice tying platform usage to token buybacks and burns.

Venice Minds routes usage fees into VVV burns

Venice launched Minds on 17 November, a system for building task-specific agents and listing them in a marketplace. Creators keep most of the margin they add, while Venice's remaining 10% platform fee buys and burns VVV. The burn is layered on an existing model: annual emissions were cut from 14 million to 2 million tokens starting 1 October 2026. November's burn of 21,657 VVV, worth about $458,000, was a record.

The token responded. Venice Token gained about 33% in the week to 25 November, even as Bitcoin and Bittensor's TAO fell. The same source cautions that the price data do not establish that revenue growth or burns caused the rally.

Bittensor: compute contracts and an earlier consensus change

Subnet 4, Bittensor's compute unit, is showing customers signing longer capacity bookings. In mid-October the network also added a mode with up to 2,500 subnet slots and fee-free PoW entry. Neither is brand new, so the news here is adoption rather than launch. Governance remains the open question.

Render, Akash and io.net: small revenue, mostly self-reported

Render and Akash together show roughly $9.3M of annualised on-chain revenue in the 20 November snapshot from DePIN Pulse. The io.net figure of about $16.3M is the company's own estimate, relayed by the tracker rather than counted on-chain. That gap is the story: real usage exists, but verifiable revenue is a fraction of the marketing numbers.

Open-Source Pulse

Open-weight momentum is concentrated in Qwen3.8-27B, while GitHub trending rewards agent infrastructure and small-model training.

Qwen3.8-27B dominates Hugging Face trending

The 23 November trending digest names Qwen3.8-27B as the week's defining release. Its base checkpoint has roughly 20,900 likes and 6.3M downloads, and quantised derivatives account for much of the follow-on activity. The Qwen3.8-27B family holds the top three weekly-likes positions.

DeepSeek V4.1 Flash targets cheap deployment

DeepSeek's V4.1-Flash-1017 is a Flash-tier multimodal text model aimed at efficient deployment, with about 5,900 likes at the time of the digest. It keeps DeepSeek in the open-weight race at the efficiency end rather than the frontier.

GitHub: agent plumbing and tiny-model training

Firecrawl continues to climb, reaching about 208,000 stars on 24 November, which makes it a default layer for agents that need web data. Minimind, a tutorial framework for training a 64M-parameter LLM from scratch, is also gaining fast, with roughly 69,000 stars and a claim of training in about two hours.

inclusionAI drops Ling-3.2-Air under MIT

inclusionAI published Ling-3.2-Air on Hugging Face. It is a 124B mixture-of-experts model with 5.5B active parameters and a 1M-token context, released under the MIT license. A permissive license at that scale is the notable part.

Deals & Regulation

Deal flow is dominated by large companies buying AI infrastructure software, chip-side capability and talent.

⚡ Update: Amazon's Decart agreement is now announced

Last issue covered reported talks. Amazon has now announced an agreement covering Decart's core software and three founders, along with much of its research staff. The deal remains subject to regulatory approval. Sources told Bloomberg that Amazon is paying about $7.5 billion, nearly twice the valuation Decart reportedly received in its May round. Anthropic had considered buying Decart and conducted due diligence before walking away. The model portfolio is excluded from the purchase (34-12).

AMD takes Taalas for $2.9B

On 23 November, AMD agreed to acquire Taalas, a deal valued at $2.9B and aimed at AI inference hardware, according to the November deal tracker. The pattern matches the broader push by chip vendors to own inference capability.

Palo Alto Networks buys Applied Compute

Palo Alto Networks agreed to buy Applied Compute, a startup that post-trains and runs open-weight models, in an all-stock deal valued at $4.5B. The startup had been valued at $3.25 billion in a funding round weeks earlier. The deal is expected to close in the company's fiscal third quarter.

Funding: Embo's $110M seed and November totals

Embo, a robotics and world-models company, raised a $110M seed led by Andreessen Horowitz, with DST Global, Nvidia and Khosla participating. November's tracker logs 160 AI deals with $363B disclosed so far.

Workflow & Tools

Tooling news is about making agents cheaper to run and easier to hand off between tools and teams.

Tasks and Elicitation go generally available

Anthropic moved two MCP features, Tasks and Elicitation, to general availability on 24 November (44-9). They are available across Pro, Max and Ultra plans and rolling out to Team and Enterprise organisations. Claude will also pass files to MCP servers rather than only text.

OpenAI merges ChatGPT and Codex into one usage meter

OpenAI is consolidating ChatGPT and Codex usage into a single meter. For teams using both products, that simplifies budgeting; it is also a sign that the two surfaces are converging.

Headroom compresses tool output before it reaches the model

Headroom compresses tool outputs, logs, files and RAG chunks before they hit the model. It claims about 20% fewer tokens for coding agents and up to 95% for JSON, and it has passed 80,000 stars.

NVIDIA's container runtime speeds agent session cloning

NVIDIA researchers published a container runtime for agents. It clones agent sessions 84 times faster than the baseline they compared against. If the speedup holds in production, it lowers the cost of running many parallel agent trials.

Research Radar

Two papers worth tracking this cycle, both about getting more out of existing models without retraining.

Loop Residuals: looping pretrained layers for compute gains

An NUS-led paper loops layers from a pretrained Qwen3 model and reports 2-4x compute gains without retraining. If the result generalises, it is a cheap route to more capacity from models you already have. Check whether the gains hold on long-context and agentic benchmarks before adopting.

Depth Pro 2: one network for metric depth

Apple's Depth Pro 2 is a single scalable network that estimates dense metric depth for images and video at native resolution, improving accuracy, boundary sharpness and temporal consistency together. It was published on 19 November and is a useful reference for robotics and video pipelines.

GameAnything: a benchmark that exposes agent limits

The GameAnything benchmark shows that coding agents can adapt reference material but still struggle with playable interactions and precise modifications. It is a useful stress test for anyone claiming agents can build interactive software.
