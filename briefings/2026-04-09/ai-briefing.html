[Launch] Z.ai / Zhipu AI Open-Weight

GLM-5.1 — 754B MoE, MIT License, 8-Hour Autonomous Tasks, Top SWE-Bench Pro

Z.ai (formerly Zhipu AI, publicly listed Chinese AI company) released GLM-5.1 on April 7–8 as an open-weight post-training upgrade to GLM-5. Architecture: 744B parameter Mixture-of-Experts, 40B active parameters, 200K context window, 131K max output. Trained entirely on Huawei Ascend 910B chips — zero Nvidia hardware. Available on HuggingFace under MIT license.

Benchmark results (verified across VentureBeat, MarkTechPost, Dataconomy): SWE-Bench Pro: 58.4 (#1) GPT-5.4: 57.7 Claude Opus 4.6: 57.3 Gemini 3.1 Pro: 54.2

The 8-hour autonomous task capability is the engineering claim that matters most: sustained multi-step agentic coding without human checkpoints. This is the practical frontier being contested — not benchmark digits, but the duration of reliable unsupervised execution. GLM-5.1 sustains it longer than any model in the open-source space to date.

MIT license means full commercial use, no usage restrictions, fully inspectable weights. This is the most commercially usable open frontier model yet released, and the Ascend-training fact has geopolitical implications: China's AI stack is no longer NVIDIA-dependent at the frontier.

⚡ Implication: The proprietary coding moat just got contested. Any workflow where you're paying for Claude Opus 4.6 or GPT-5.4 for coding tasks should run a GLM-5.1 comparison this week. Monitor — no urgent action unless you have a cost-sensitive coding pipeline.

[Launch] Anthropic Security

Claude Mythos Preview + Project Glasswing — Zero-Days Found in Every Major OS; Access by Invite Only

Anthropic announced Claude Mythos Preview on April 7 — a new general-purpose model with exceptional computer security capabilities, made available exclusively as a gated research preview through Project Glasswing. Partners with gated access: AWS, Apple, Broadcom, Cisco, CrowdStrike, Google, JPMorganChase, Microsoft, and NVIDIA. Anthropic committed $100M in model usage credits to the project.

The capabilities disclosed are significant: Mythos Preview is capable of identifying and exploiting zero-day vulnerabilities in every major OS and every major web browser when directed by a user to do so. It fully autonomously found and exploited a 17-year-old remote code execution vulnerability in FreeBSD (root access via NFS). Over 99% of vulnerabilities found have not yet been patched — coordinated disclosure is in progress.

Anthropic has no plans to make Mythos Preview generally available. The eventual goal is safe deployment of Mythos-class models at scale — this preview is the first step. The implicit read: Mythos represents a capability tier meaningfully above the current public model stack. Glasswing is the framework for responsible deployment of that capability before public release.

⚡ Implication: This is the most significant unreleased Anthropic model signal since Claude 3 Opus. It's not in your workflow yet — and may not be for 12+ months. Monitor. If you are in defensive cybersecurity, explore Glasswing partnership eligibility.

[Update] GitHub Trending Viral

MemPalace — 23k GitHub Stars, Benchmark Claims Contested by Developer Community

MemPalace (github.com/milla-jovovich/mempalace) went viral after April 6 launch: 23k+ stars, 3k+ forks. Built by actress Milla Jovovich and developer Ben Sigman. Claims "96.6% on LongMemEval" — the highest-scoring free AI memory framework. The concept is solid: organise agent memory spatially (palace → wings → halls → rooms → closets → drawers) using the method of loci, storing everything and making it findable via structure rather than AI curation.

The controversy: developer community analysis (Cybernews, Substack reviewers) found the benchmark claims don't fully substantiate in the code — headline score relies on ChromaDB vector search doing most of the heavy lifting. The README overstates what the spatial structure adds vs. plain RAG. Treat it as an interesting memory architecture concept, not a production-ready system with verified benchmark performance. [Unconfirmed benchmark claims — see Cybernews analysis]

⚡ Implication: Worth reading the architecture pattern (spatial agent memory organisation is a genuinely useful design), but don't implement in production on the basis of the headline benchmark. Wait for community replication of the 96.6% claim. Monitor — no action.

§07
TriAttention (MIT/ZJU/NVIDIA) delivers 6.3x throughput and 10.7x KV cache memory reduction — the most commercially relevant inference paper of the week.
[Research] MIT · ZJU · NVIDIA Inference

TriAttention — Trigonometric KV Cache Compression: 6.3x Throughput, 10.7x Memory Reduction

MIT · Zhejiang University · NVIDIA — April 2026

Finding: TriAttention predicts which attention heads and key-value pairs matter using a trigonometric series approximation — computed in the first 30 tokens — and prunes the KV cache accordingly before it grows. Result: up to 6.3x higher throughput and 10.7x reduction in KV memory without meaningful accuracy loss on standard benchmarks.

Why it matters in 6 months: KV cache is the primary memory bottleneck preventing longer-context deployment at scale. If TriAttention's results hold on diverse workloads, it unlocks practical 1M+ token inference on hardware that currently struggles with 200K. NVIDIA co-authorship signals this is on the production roadmap — watch for vLLM and TensorRT integration. This is the type of paper that becomes an inference serving feature quietly and then suddenly "just works" in your LLM runtime.

⚡ Implication: Monitor for vLLM or llama.cpp integration. When it ships, long-context inference costs drop significantly — relevant for any RAG pipeline or agentic loop that currently truncates context for cost reasons.
