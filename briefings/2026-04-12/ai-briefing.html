Claude Code v2.1.100–v2.1.101 — MCP Lazy-Loading, Write Speed, Voice, Security Fix

Claude Code v2.1.100 (approximate April 9–10 window) and v2.1.101 (April 11) shipped a dense set of changes. The standout feature is MCP Tool Search / lazy loading: MCP tools are now fetched on demand rather than pre-loaded into context. For heavy MCP users with large server sets (Notion + Gmail + Calendar + custom servers), this reportedly cuts MCP-related context usage by up to 95%.

Other confirmed changes: Write tool diff computation is 60% faster for large files. Voice mode now supports push-to-talk modifier combos. Headless permission deferral — headless sessions can pause at a tool call and resume with -p --resume, enabling supervised autonomous runs. New /team-onboarding command generates a teammate ramp-up guide from local Claude Code usage patterns. Security fix: command injection vulnerability in LSP binary detection patched in v2.1.101. [Sources: GitHub Claude Code releases, Releasebot — confirmed]

⚡ Implication: The MCP lazy-loading is directly relevant to your setup (Notion, Gmail, Calendar, Whoop MCPs active). Enable it and measure whether your briefing runs feel lighter on context. The headless permission deferral also unlocks more reliable background scheduled task runs.

MCP server authors can now set anthropic/maxResultSizeChars in a tool's tools/list entry, up to a hard ceiling of 500,000 characters. Tsinghua University / Zhongguancun Academy · April 2026

The practical implication: academic benchmark leaders will have shorter shelf lives.

[Research]

LLM Stochasticity Illusion — Google DeepMind: LLMs Are Biased, Not Random

Google DeepMind · April 2026

One-line finding: LLMs consistently produce statistically biased outputs when asked to generate "random" samples — they are not random, they are predictably skewed, and that skew is reproducible.

Why it matters in 6 months: Any application that relies on LLMs for sampling, simulation, A/B test generation, or stochastic decision-making has a hidden bias problem. The fix is straightforward: use external PRNGs or map truly random inputs to target distributions deterministically. But most developers building on LLMs don't know this bias exists. [Source: Google DeepMind — confirmed via devflokers.com research digest]
