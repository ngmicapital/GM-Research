§07 Research Radar

The most practically-impactful paper this week is Google's TurboQuant (KV cache compression to 3 bits, 8× speedup on H100, zero accuracy loss) — published at ICLR 2026 with QJL/PolarQuant component papers at AISTATS 2026, and already triggering implementations in llama.cpp and MLX.

TurboQuant — KV cache quantization to 3 bits, 8× attention-logit speedup, zero accuracy loss (Google DeepMind, ICLR 2026) ⚡

Per Google Research blog, VentureBeat, Tom's Hardware, TrendForce: TurboQuant is a training-free, online vector-quantization algorithm from Google DeepMind that compresses LLM key-value (KV) cache from 16 bits to 3 bits with zero measurable accuracy loss, delivering up to 8× speedup on attention-logit computation on NVIDIA H100 GPUs. The mechanism: a random rotation of the data vectors simplifies the geometric distribution, after which a standard quantizer can be applied to each part of the vector individually with bounded reconstruction error. The component algorithms — QJL (Quantized Johnson-Lindenstrauss transform) and PolarQuant — were submitted to ICLR 2026 and AISTATS 2026 respectively. Cost impact: ~50% inference cost reduction in the cited benchmarks; memory impact: KV cache shrinks at least 6×, which is the binding constraint for long-context inference on existing hardware. Implementations under active development for llama.cpp and MLX per the GitHub discussion thread (ggml-org/llama.cpp#20969).

⚡ Implication in 6 months: KV cache is the long-context bottleneck — every additional token of context multiplies the cache footprint, which is why frontier-lab "long-context" pricing has stayed expensive. A 6× cache reduction with zero accuracy loss is the rare "no tradeoff" win, and the algorithm being training-free means it can be retrofitted onto existing deployed models without retraining. Predicted path: by Q3 2026, vLLM and SGLang will have first-class TurboQuant-style KV-cache support; Anthropic, OpenAI, and Google will be using it (or their own equivalents) in production by year-end. Combined with DFlash's algorithmic 6× speedup (Issue #41 §07) and NVIDIA's Vera Rubin / Groq 3 LPU 35× per-MW claim (Issue #41 §08), the per-token inference economics in H2 2026 are likely 10–20× cheaper than today on the same model quality. For AI-DePIN compute basket: same Jevons-paradox argument — cheaper inference grows total demand faster than per-token cost falls, structural tailwind on the 12-month horizon. For memory chip stocks (incidentally): the TrendForce note is correct that this compresses near-term DRAM/HBM demand assumptions; not directly relevant to dc but useful colour for the Market Briefing thread. → Market Briefing.

🔬 Plain-English Explainer — why "KV cache compression" matters and why TurboQuant is a 6× win

When an AI like Claude reads a long document or holds a long conversation, it has to keep a running "memory" of every word it has already seen so it can answer your next question coherently. That memory is called the KV cache (key-value cache). The catch: every additional word you add to the conversation makes that memory bigger, and the memory has to live in fast on-GPU storage that's expensive and limited. This is why long-context AI is more expensive per token than short-context AI — you're not just paying for the new words, you're paying for the GPU memory needed to hold the running tally. Think of the KV cache like the running notes a translator scribbles while listening to a long speech: the longer the speech, the more notebook pages they need, and notebook space on a GPU is rare. What TurboQuant does: it shrinks each "note" from 16 bits to 3 bits (about 1/6 the space), with no measurable loss in accuracy, by first rotating the underlying data vectors so that they're easier to compress, then applying a standard compression scheme. The result is that the same GPU can now hold 6× longer conversations in the same memory, and the math operations on those compressed notes run up to 8× faster — both wins, no tradeoff. For traders, this matters because the per-token cost of long-context AI is what underwrites the entire enterprise-AI economy — every analyst report processed, every legal document reviewed, every financial filing digested is a long-context inference job, and the cost-floor for those jobs has been the binding constraint on adoption. A 6× cache reduction means enterprises who couldn't afford to run AI on their 100-page contracts at $2 per query can now run it at $0.33. Multiplied by every long-context inference job in 2026 H2, the demand for inference compute grows much faster than the per-token cost drops — which is the structural reason decentralised compute (TAO subnets, Akash GPUs, Render network) keeps getting more valuable as inference gets cheaper, not less.
