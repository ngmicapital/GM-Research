§08 — Technicals

The most important technical advancement this week is Cerebras's 2,522 tokens-per-second on Llama 4 Maverick — more than 2x NVIDIA Blackwell B200's 1,038 tok/s on the same model — and it shifts the inference-economics conversation from "GPU vs GPU" to "memory architecture vs HBM bandwidth ceiling."

Cerebras 2,522 tok/s on Llama 4 Maverick — 2.4x Blackwell B200 ⚡

Update Benchmark Cerebras 2,522 tok/s NVIDIA Blackwell B200 1,038 tok/s 44GB on-chip SRAM · 21PB/s memory bw

Per Artificial Analysis benchmarks: Cerebras's wafer-scale engine printed 2,522 tokens per second on Llama 4 Maverick (a ~400B parameter model), against NVIDIA Blackwell B200's 1,038 tok/s on the same workload — a 2.4x throughput delta. The architectural mechanism: Cerebras bypasses the HBM bandwidth ceiling that limits all current GPU inference, using 44GB of on-chip SRAM with 21 petabytes/sec of memory bandwidth — roughly 7,000x the bandwidth of NVIDIA's H100.

⚡ Implication (3–6mo): If Cerebras maintains the 2x throughput delta on frontier-class models, the API-pricing curve for fast-inference workloads (live coding assistants, real-time agent loops, voice models) decouples from GPU-supply-constrained pricing within two pricing cycles. Anthropic, Google, and OpenAI's Cerebras-deployment decisions become the leading indicator. For dc's stack, this only matters when latency-sensitive workloads enter the briefing pipeline — currently irrelevant, but the watch is whether Anthropic adds a Cerebras-backed inference SKU at lower pricing within Q3.

Update Launch 288GB HBM3e per GPU 50x throughput/MW vs Hopper 11x faster inference on LLMs

NVIDIA's Blackwell Ultra (GB300 NVL72 rack-scale and HGX B300 NVL16) is shipping into AWS, Google Cloud, Azure, Oracle, CoreWeave, Crusoe, Lambda, Nebius, Nscale, Yotta, YTL. The GB300 NVL72 connects 72 Blackwell Ultra GPUs at rack-scale — the architectural target is explicitly agentic-AI workloads that combine sophisticated reasoning with iterative planning.

🔬 Plain-English Explainer — What the Cerebras result actually means

Think of an AI model like a giant lookup table. Every time the model produces a single word, it has to consult every entry in the table to pick the right one. With current GPUs (including NVIDIA's flagship Blackwell B200), most of the time is spent shuttling that table back and forth between the chip's "thinking" area and its "memory" area — like trying to read a book where every page is in a different room. The faster the chip can move the pages around, the faster it generates text. That shuttling is called "memory bandwidth," and right now it's the bottleneck — not how clever the chip is.

Cerebras built a different shape of chip — one giant wafer where the thinking area and the memory area are literally the same room. The entire lookup table sits on the chip itself. The "page-fetching" problem disappears, because there are no pages to fetch. That's why Cerebras can produce text more than twice as fast as NVIDIA's best chip running the same model. For traders, this matters because: cheap fast inference is the input to every AI product. If Cerebras (or competitors using the same architectural idea) scale up, the unit-economics of running an AI assistant, an automated briefing pipeline, or a 24/7 trading agent get cheaper without the model itself getting smarter. The agent-AI thesis (DePIN compute, AI tokens, AI-x-crypto basket) becomes cheaper to underwrite. The risk: NVIDIA still controls training, and most production deployments still live on its hardware — so the inference-side disruption takes 2–3 capital cycles to actually show up in pricing.
