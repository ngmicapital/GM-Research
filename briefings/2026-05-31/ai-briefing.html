§07 — Research Radar

Agent memory became the attack surface in May 2026 — the live research cluster is memory poisoning and defense for memory-based LLM agents (arXiv 2601.05504), temporal-fidelity memory (Memory-T1), and the agent-interoperability standards stack (A2A, ACP, ANP, MCP Tasks Primitive) — which lands directly on dc's own file-based persistent-memory system and the "verify recalled memory before acting" discipline already baked into it.

Memory poisoning — the new agent attack surface

Research Security

The dominant late-2025 → 2026 research shift is that persistent agent memory is now a first-class security surface. The canonical reference is "Memory Poisoning Attack and Defense on Memory-Based LLM-Agents" (arXiv 2601.05504), which formalises attack and defense models implemented at the middleware layer (e.g. an "Agent Memory Guard"). Adjacent work: Memory-T1 (arXiv 2512.20092) trains agents to maintain chronological fidelity — what was true at which point in time — across multi-session contexts, and the AgeMem framework (arXiv 2601.01885) models an agent's operational state as short-term context + memory + temporal components. This is the through-line of the "May 2026 memory inflection."

⚡ So what: This is unusually on-point for dc. The briefings-stack runs on a file-based persistent memory (the memory/ directory + MEMORY.md index), and the harness already injects the warning that recalled memories "reflect what was true when written — verify before recommending." The memory-poisoning literature is the academic articulation of exactly that risk: a stale or adversarial memory file can silently steer an agent. The take-home is to keep treating recalled memory as evidence to verify, not instruction to follow — and to prune stale facts proactively (the consolidate-memory pass).

Agent-interoperability standards consolidating (carry-adjacent)

Research

Four standards are formalising the agent-communication taxonomy (from arXiv 2505.02279): Agent2Agent (A2A) for cross-organisational peer communication, Agent Communication Protocol (ACP) for high-throughput intra-cluster systems, Agent Network Protocol (ANP) for trust-decentralised federated networks, and the MCP Tasks Primitive (SEP-1686). As multi-agent orchestration (Dynamic Workflows, §02/§06) goes mainstream, the protocol layer underneath it is standardising in parallel.

⚡ So what: No action today — but the MCP Tasks Primitive is the one to track, since it sits in the same MCP ecosystem the briefings-stack already depends on. Worth a read when the next coordination-protocol or parallel-agent project spins up.
