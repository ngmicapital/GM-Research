claude-context — semantic codebase MCP server, any-agent-friendly ⚡

Workflow GitHub trending #1 this week MCP-native

claude-context is a semantic code-search MCP server that lets any MCP-compatible coding agent (Claude Code, Cursor, Windsurf, Cline, VS Code, etc.) query an entire codebase as context. The interesting design choice is that it's MCP-first, not Anthropic-only — the same server serves every major coding-agent client, which makes it a credible "Postgres of context" candidate.

⚡ So what: Worth trying on the briefings-site repo this week. TradingAgents — multi-agent debate pattern, back in trending after 5-month dormancy

Workflow Research Dec 2024 paper Re-trending May 2026

The TradingAgents repo — a multi-agent debate pattern modelling a trading firm with 4–5 role-specialised agents — is back in GitHub trending for the second time this month (it also flagged in Issue #43 as a HuggingFace re-emergence). The repo is December 2024 vintage, which is the interesting part: the multi-agent abstraction has become more useful as Anthropic's multi-agent orchestration GA'd, not less. The pattern generalises to any domain where you'd hire 4–5 specialists in real life — legal, research, design review.

⚡ So what: Read the TradingAgents source for the agent-handoff prompt structure — the pattern of having a "researcher" agent feed a "challenger" agent who feeds an "executor" agent is the one that maps cleanly to dc's existing briefing-skill stack. Apply to the legal-brief skill: split into "case-finder" → "policy-analyst" → "drafter" and benchmark vs the current monolithic skill.

pi-mono — agent toolkit with interchangeable parts (LLM API, TUI, web UI, Slack bot)

Workflow GitHub trending this week

pi-mono is an agent toolkit shipped as a monorepo with deliberately interchangeable parts: a coding-agent CLI, a unified LLM API, TUI and web UI libraries, a Slack bot. The interesting thing isn't any single component — it's that the components are designed to swap. If you want a Slack-frontend instead of CLI, replace the front-end without touching the agent core.

⚡ So what: Architecturally the right direction for the briefings-site skill stack — currently each skill (AI briefing, legal brief, market briefing) re-implements the same web-search → write-HTML → distribute-to-Notion-and-Gmail pattern. Worth reading pi-mono's component-boundary design as a template for the next refactor pass.

ComplexMCP — LLM agent eval in dynamic, interdependent, large-scale tool sandboxes

Research arXiv · May 2026

ComplexMCP is the first published agent benchmark designed explicitly around dynamic-tool environments — i.e., environments where the tool surface itself changes during the agent's trajectory. The premise: existing agent benchmarks (Gaia2, BFCL, etc.) assume a fixed tool set, but production MCP environments have tool-availability churn. The eval set is interdependent (calling tool A unlocks tool B), dynamic (tools come and go), and large-scale (hundreds of tools).

⚡ So what: Important framing because the briefings-site skill stack is exactly a dynamic-tool environment (MCP connectors load on demand, plugins gate behind authentication). If ComplexMCP becomes the standard agent eval for production multi-agent systems, Anthropic's MCP-first posture gets a measurement-layer tailwind.

STALE — can LLM agents detect when their memories are no longer valid?

Research arXiv · May 2026

STALE is the agent-memory paper that asks the right question: not "can agents have memory" (yes, Mem0, Letta, MemGPT, Anthropic memory all do this) but "can agents detect when their stored memories are stale or no longer apply." The construction is a controlled set of memory-poisoning scenarios where ground-truth changes mid-trajectory and the agent must catch the drift.

⚡ So what: Directly relevant to dc's auto-memory system in this repo (memory/MEMORY.md and per-file memory entries). The CLAUDE.md memory hygiene rule explicitly says "memory records can become stale" and "verify before acting on memory" — STALE is the formal benchmark for whether the agent actually does that. Worth a re-read once the paper has a code release.
